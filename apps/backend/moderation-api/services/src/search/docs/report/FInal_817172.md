2. Technical Contributions
I was responsible for building the filter system for the restaurant discovery feature. The two main features I implemented were the Cuisine Filter Options and the Global Clear All Filters.
For the Cuisine Filter Options, I created a component that displays all available cuisine types as interactive toggle buttons. Users can see all options at a glance and click to select their preferred cuisines. I implemented multi-select functionality that allows users to select multiple cuisines simultaneously. The component maintains an array of selected cuisines and provides visual feedback by changing button colors when active. I also added a selection counter so users know how many cuisines they have selected.
For the Global Clear All Filters, I implemented a single button that resets all filters to their default states simultaneously. This improves user experience by providing a quick way to start over without manually clearing each filter individually.
I built these components using React with functional components and hooks. I used useState for local state management and connected the filters to the backend API by constructing query parameters from filter states. I handled loading and error states appropriately to provide feedback to users. For user experience, I made the filter system mobile-responsive using Tailwind CSS and added visual feedback throughout—buttons change color when selected and counters show active filters.
