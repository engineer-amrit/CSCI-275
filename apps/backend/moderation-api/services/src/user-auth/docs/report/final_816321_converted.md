## 2. Summary of My Contribution

During this project, my main contribution was research, discussions,
planning, sharing ideas, and helping prepare the project documents. My
team was responsible for the User & Authentication System of the
Restaurant Rating Application. This part included user registration,
login, password management, user profiles, and user roles.

I did not personally write the code for the project. Because of this, I
do not want to claim coding work that was completed by other members. My
contribution was mainly focused on understanding the project,
researching useful features, discussing ideas with my group, and helping
prepare the required documents.

At the beginning of the project, I helped research different features
that are commonly available in restaurant review applications. I looked
at features such as user reviews, star ratings, restaurant search and
filters, restaurant profiles, photo uploads, menus, saved restaurants,
location-based search, user profiles, and notifications.

I also researched some other useful features, including restaurant
rankings, ratings for food, service, value and atmosphere, personalized
recommendations, map-based restaurant discovery, wait-time prediction,
offline access, and automatic translation. I discussed these features
with my group members and shared my ideas about which features could be
useful for our application.

Another part of my contribution was discussing the different types of
users for our application. I helped identify users such as Guest Users,
Registered Users, Restaurant Owners or Business Representatives,
Customers, System Administrators, and Moderators.

I also participated in discussions about the features assigned to our
team. Our team was responsible for User Registration and Onboarding,
Authentication and Session Management, Password Management, User Profile
Management, and Authorization and Roles. I shared my ideas about these
features and helped organize the information needed for our project.

I also helped with the Software Requirements Specification for our
system. I participated in discussions about what the User &
Authentication System should do and helped organize the requirements.

For user registration, I helped discuss what information should be
required when a new user creates an account. This included the user's
full name, email, password, and an optional profile photo. I also
discussed features such as email verification and checking if an email
is already registered.

For the login and authentication system, I participated in discussions
about email and password login and other login options such as Google,
Facebook, and Apple. I also discussed features such as "Remember me,"
logging out from one device, and logging out from all devices.

Another area I helped discuss was password management. This included
forgot password, resetting a password through email, changing a
password, and checking password strength. The requirements also included
rules for creating a stronger password.

I also participated in discussions about user profile management. This
included allowing users to view and edit their display name, bio,
profile picture, and location. Account deactivation and account deletion
were also discussed as part of the profile system.

Another part I helped discuss was user roles and permissions. The system
included roles such as Guest, Registered User, Reviewer, Moderator, and
Admin. Different roles have different permissions so that users can only
access the features they are allowed to use.
